The Crafting Web

Every item in the game and how it's made, as one graph. 117 items, 195+ merge links, five tiers — all built on a single rule: merge two items to make a third. No crafting stations. Search a name, drag nodes, hover to trace a chain, click for the recipe.

This is the full production graph behind the design doc — the same 117 items exported as an interactive map. The point isn't the item count; it's that one merge rule scales to the whole tree and stays readable. Weapons run on ore ingots (Copper → Iron → Silver → Hell); armour and tools run on structural catalysts. Difficulty phase gates which materials drop, so climbing tiers means surviving longer.
